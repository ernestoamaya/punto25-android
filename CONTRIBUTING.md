# Contributing to Punto25

Punto25 is currently in an owner-controlled Alpha phase.

Unsolicited external pull requests are not accepted at this stage. Public visibility of the source is not an invitation to contribute code and does not change the ownership/licensing terms in `LICENSE` and `COPYRIGHT.md`.

Security reports should follow `SECURITY.md` and should not be posted publicly when they contain exploitable details, credentials or private data.

The internal development workflow uses narrow branches, pull-request validation, automated tests/builds and physical-device validation where required.

If external contributions are accepted in the future, contribution and intellectual-property terms will be defined before accepting third-party code.
